# 批量生成带货视频

上传产品图，一次生成多条可直接投放的用户原创内容或剧情带货视频。自动完成创意策划、达人参考图、分镜提示词、视频生成与成片拼接，让批量制作更快、更稳、更省心。

## 适合谁用

- 电商卖家：快速扩充短视频素材，持续测试不同创意。
- 内容团队：用统一流程批量生产，同时保持每条创意独立。
- 品牌运营：面向不同市场生成本地化内容，减少重复沟通。

## 核心能力

- 支持原创内容与剧情带货两种形式。
- 一次生成一至十条独立视频。
- 自动生成创意、达人参考图与逐段分镜提示词。
- 支持多段视频生成、任务恢复与自动拼接。
- 对产品事实、参考图和人物一致性进行严格校验。

## 使用方式

向智能体提供产品图片，并说明希望生成的视频数量、时长、目标市场或创作要求。技能会先展示完整配置供确认，确认后自动执行后续流程。
